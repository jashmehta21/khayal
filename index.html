How to get a free key (2 minutes)
  1. Open platform.openai.com/api-keys (or aistudio.google.com/apikey for Gemini).
  2. Create a key and copy it.
  3. Pick the matching provider above, paste the key, tap Test.

Using OpenAI instead? Choose OpenAI above and paste a key from platform.openai.com/api-keys. It bills your API credits, and this app's usage is tiny — cleanups and questions cost a fraction of a cent each.

Something else? Pick "Other" and give the API address — anything that speaks the OpenAI format works, including xAI (https://api.x.ai/v1), Groq and OpenRouter. Note a Grok subscription is separate from xAI API credits.

Google Workspace accounts usually fail here: AI Studio is admin-controlled and off by default, so keys made there resolve no models.

The key stays on this device only — it is never uploaded and never stored in the app's code. With smart cleanup on, the words you dictate are sent to Google to be rewritten; everything else in Khayal still stays on your phone.
